## 背景(为什么)
REQ-008 D3 拍板(2026-07-05):**非技术用户(小白)正式纳入目标用户群**,但分期执行——当前阶段只做「规范文档」,新手引导/错误自解释全量/支持面等大量工作暂不做(用户原话见 [debates/2026-07-05-req008-positioning-briefs.md](../debates/2026-07-05-req008-positioning-briefs.md) 拍板记录)。现状:无任何面向使用者(而非开发者)的产品文档;小白经「登录即代付」能零配置起步,但装-登-用路径与常见错误无文档可查。

## 目标(做什么)
一套小白能懂的使用文档:安装(dmg/公证/首启)→ 登录(deep-link 流程)→ 开始对话;常见错误 FAQ(登录失败/网络/模型额度);高级功能(BYOK/MCP/自动化)只做入门级索引(指向 power user 文档,不重写)。

## 验收标准
1. 覆盖「下载→安装→登录→第一次对话」全路径,零术语假设(不假设懂 API key/终端);
2. 常见错误 FAQ ≥ 8 条,与 B11 错误呈现文案一致(只做文档,不承诺改产品);
3. ~~落点拍板:in-app 帮助 vs alpha-web vs 双落点——开工时确认~~ → **已拍板(2026-07-05,S18 开批):落 alpha-web(C 仓)**;app 内「帮助」菜单加一条链接指过去(一行,不算双落点);
4. 中文优先;英文随 C20(i18n 专项)节奏。

## 非目标
- 新手引导(onboarding 向导)、错误自解释全量(B11 余项)、客服/支持渠道——D3 明确暂缓;
- 不为文档改产品行为。
