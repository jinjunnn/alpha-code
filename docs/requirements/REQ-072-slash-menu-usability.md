## 背景/报障(用户,2026-07-09)

`/` 命令弹框(alpha 统一 composer 的自动补全,REQ-038/055/066 演进而来)当前很不好用:

1. **键盘上下键无法切换选中项**,只能鼠标点;
2. **部分已装技能不出现在列表里**,必须输入首字母搜索才出现;
3. **搜索逻辑有问题**(体感:该搜到的搜不到/顺序乱);
4. 展示层粗糙(对照 Codex 弹框参照图):无 icon、无分组、内置技能名称/简介全英文、"个人(自装)"内容无标识。

## 机制排查(登记时已核,根因钉死)

均在 `ui-mac/src/renderer/alpha-ui/composer-autocomplete{.tsx,-core.ts}`:

1. **键盘导航失效 = active 重置竞态**(实现在而失效):`onKeyDown` 每键 `queueMicrotask(bump)`(`composer-autocomplete.tsx:270`,为跟踪光标)→ `view`/`items` memo 重算出新引用 → effect「items 变即 `setActive(0)`」(`:214-217`)在微任务后立即把选中重置回第 0 项。↑↓ 的 `setActive` 生效后一瞬被覆盖,视觉上高亮不动。鼠标可用因 mousemove 不经 bump。**修复方向**:active 重置只应发生在 query/触发 token 实际变化时(按 items 内容 key 比对或按 trigger signature),而非引用变化;
2. **列表不全 = 12 条硬帽**:`[...custom, ...builtin].slice(0, 12)`(`:204`),顺序 = 引擎 `command.list` 返回序(非字母序)。技能多于 ~10 个时排后者永不显示,靠搜索挤进前 12 才可见。**修复方向**:全量渲染 + 弹框 max-height 滚动 + 选中项 `scrollIntoView`(键盘导航配套);如需性能帽,帽值远大于常见量级并 loud(不静默截断);
3. **搜索只匹配名字、无排序**:自定义命令仅 `name.includes(q)`(`:182`),描述不参与;builtin 匹配 slash+title;无前缀优先级(prefix > substring),命中序 = 引擎序;**无结果时菜单直接消失**(`open()` 要求 `items.length>0`),无「无匹配」空态。**修复方向**:搜索域 = 名称 + 描述(+ 中文名,见 T2);排序 = 前缀命中 > 子串命中,同级按字母;空态显示「无匹配命令」不闪没。

## 期望方向(展示重设计,Codex 参照稿对标;三点建议待用户确认即钉)

1. **双维标识,各占一位**:行首 **icon = 类型**(技能/命令/agent/文件;@ 菜单同款);**右侧标注 = 来源**,现有五档(内置/技能/项目/MCP/导入)收敛为**内置 / 个人(自装+导入)/ 项目 / MCP**——补上「这是你自己装的」视角(现有「技能」徽标是通道视角,不回答归属);
2. **分组呈现**:平铺「命令」单节 → 分节(内置命令 / 技能 / 项目命令 / MCP),节内字母序,搜索时跨节按排序规则合并;
3. **中文名/简介的供给通道**:出厂件与 catalog 精选件补 zh 名称+简介(catalog 下发通道现成,ADR-023/ADR-014 供给链);**外来第三方技能如实显示作者原文,不机器翻译**(译错比英文更糟,C28 反 placebo);`/init` `/review` 描述文案随 REQ-062 换芯一并中文化(config 同名覆盖通道);
4. **杂项**:键位提示页脚(↑↓ 选择 · ↵ 确认 · esc 关闭);描述截断加 title/tooltip。

## 分期

- **T2 展示重设计**:类型 icon + 来源标注收敛 + 分组 + 中文名供给通道 + 杂项。

## 验收标准

1. `/` 打开后 ↑↓ 可循环切换选中,高亮随键盘移动且滚动跟随;Enter/Tab 确认、Esc 关闭(IME 组合态 Enter 不误触,既有保护不回归);
2. 已装技能**全量可见**(滚动可达),不再依赖搜索才出现;列表有稳定排序(非引擎返回序);
3. 搜索命中名称与描述;前缀命中排前;无结果显示空态而非菜单消失;
4. (T2)每行有类型 icon;来源标注区分 内置/个人/项目/MCP;个人(自装/导入)内容可一眼识别;
5. (T2)出厂件与 catalog 精选件显示中文名+中文简介;外来件如实原文;`/init` `/review` 描述中文化;
6. 既有语义不回归:治理禁用过滤(REQ-066/067)、来源归类、custom 回填 `/name `、builtin trigger、@ 菜单 mention parts(单测已锁的全部保留);
7. 零改上游源码;真机截图核验([[visual-verify-required]])。
