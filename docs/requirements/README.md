# Legacy requirements

This directory is retained as migration and design history. Active requirements
live in [`alpha-code` Issues](https://github.com/jinjunnn/alpha-code/issues) or,
for cross-repository outcomes, in
[`alpha-work` Issues](https://github.com/jinjunnn/alpha-work/issues).

Do not create new requirement files here or update delivery status, priority,
owner, or Sprint fields. Move reusable contracts and design content into the
appropriate durable documentation and link it from the GitHub Issue.
