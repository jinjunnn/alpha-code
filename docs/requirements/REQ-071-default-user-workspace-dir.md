## 背景/诉求(用户直提,2026-07-09)

当前产品在用户机器上的自有落点**全部是隐藏目录**:项目级 `.alpha/`(harness 产物,ADR-019)+ 全局 `~/.alpha/`(安装物/账本/automations)+ Electron userData(内部件)。用户的"数据/工作区"没有一个**可见的默认目录**。

用户期望:提供默认工作目录 **`/Users/<user>/Alpha`(`~/Alpha`)**——用户数据的默认落点,Finder 可见、可理解,对齐常见桌面产品心智(用户不必先自己想好"该把项目放哪"才能开始用)。

## 机制现状(登记时已核,锚点)

- **无默认目录概念**:打开/新增项目 = 原生目录选择器(`ui-mac/src/main/ipc.ts:130` `open-directory-picker`),`defaultPath` 由调用方传、现无统一约定;`ALPHA_OPEN_DIR` env 仅测试/无头核验短路用。
- **onboarding 不建目录**(`AlphaOnboarding.tsx`:登录引导为主,无首个项目/目录供给步)。
- **无项目态的产物没有可见落点**:automation run 记录/云任务 artifact 均落**项目内** `.alpha/runs/`(ADR-019/ADR-022)——对还没有任何项目的新用户(尤其非技术用户画像,POSITIONING 第二画像「登录即代付零配置」),这条链路缺起点。
- **`.alpha` 纯度口径(REQ-065/ADR-019)不冲突**:`.alpha` 定位是 harness 产物目录(用户自有内容 + 账本),不是"用户文档区";`~/Alpha` 定位是**用户可见工作区**(普通目录,作为项目使用时内部照常有自己的项目级 `.alpha/`),两者正交。

## 分期

- **T1 基础供给**:lazy 供给 + chip 默认接线 + 选择器 defaultPath + 无项目态自动化/云任务目标项目 = `~/Alpha`;
- **T2 契约配套**:目录契约落地(子目录按需建)+ 内置技能 `alpha-workspace`(教总结/记忆写入约定)+ 预置「每日总结」自动化模板(默认不开)+ 云任务可见副本白名单受控扩展(拍板归此期)。

## 验收标准

1. 全新用户(无任何项目)零选择开始:home 项目 chip 默认 `~/Alpha`,新会话直接可发;目录在首次需要时被创建,Finder 可见;
2. 目录选择器默认路径指向 `~/Alpha`(用户仍可任选其他目录,不强制);
3. 无项目态自动化/云任务以 `~/Alpha` 为目标项目,run 机器产物照旧落 `~/Alpha/.alpha/runs/`(ADR-019/022 语义不动);
4. 既有用户零打扰:已有项目列表/会话不迁移、不改动、chip 仍默认上次使用;`~/Alpha` 已存在同名目录时不覆盖、不清理(如实沿用);
5. `~/Alpha` 是普通项目目录:作为项目打开时内部照常生成项目级 `.alpha/`,不承载系统件(REQ-065 纯度口径不破);
6. (T2)内置技能 `alpha-workspace` 生效后,会话内"写总结/记忆"落点与命名符合 ADR-025 目录契约(英文子目录);「每日总结」自动化模板存在且**默认不开**,开启后按日期产出 `Journal/YYYY-MM-DD.md`;
7. (T2)云任务可见副本落 `Outputs/`,写盘经受控白名单(消毒/体积帽与 ADR-021 回流守卫同款);机器产物不上移;
8. 零改上游源码;真机截图核验([[visual-verify-required]])。

## 非目标

- 不迁移/接管任何既有目录(`.alpha`、`~/.alpha`、用户已有项目)——只做**新增供给**;
- 不改 `.alpha`/harness 产物的落点语义(ADR-019 体系不动);
- 不做 iCloud/同步/备份类能力(纯本地目录);
- 不含记忆**能力本体**(跨会话记忆的读写/注入机制)——本项只钉落点契约,能力另立 REQ。
