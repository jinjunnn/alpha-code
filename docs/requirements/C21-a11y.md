## 背景/证据
Dialog 无 focus-trap/焦点恢复;model-picker-add 无键盘/Escape、toggle 与删除键 click-only;model picker 非 listbox 无方向键;三个菜单无 Escape;composer-controls 零 aria;reduced-motion 被硬编码时长绕过;主输入框 focus 环对比 1.52:1、`--a-text-tertiary` 正文 4.09/4.12:1 均 < AA(`tokens.css:15,157`)。

## 验收标准
1. Dialog:focus-trap + Escape + 关闭后焦点恢复(alpha-ui/Dialog 一处修,全局受益);
2. 两个 picker:键盘可达(方向键/Enter/Escape,listbox 语义);菜单 Escape;
3. 对比度:focus 环与 `--a-text-tertiary` 提到 ≥AA(tokens 级修改,截图取证);
4. `prefers-reduced-motion` 尊重(动画时长归零路径)。
