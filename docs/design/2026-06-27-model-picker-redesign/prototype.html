关于美学方向：本稿刻意走「精炼克制」(Linear / Raycast 调性)而非张扬的视觉冲击——因为它要嵌进 alpha-code 既有 cool-graphite 设计系统、与终端/会话共存。前端 design 技能的「大胆」在此体现为信息架构的果断(代理 / 直连 / 自定义三层、登录态四象限)与细节的精确(hairline 分隔、tabular 倍率、stagger 入场、token 化深色),而非花哨装饰。审计文档本身的标题用 Fraunces 衬线 + JetBrains Mono 标签,与产品 UI 的系统字体区分,标明「这是设计稿」。

02 登录态总览

四种账户态并排,供一眼审计差异:banner 文案/色、代理组锁定与否、主行动按钮。BYOK 国内直连组在任何态都可用。

03 自定义节点 / 供应商流程

点上方原型底部「＋ 添加自定义节点 / 供应商」即可体验。四个国内供应商为快速预设(只需粘 Key),「其他 / 自定义」走全字段表单(OpenAI / Anthropic 兼容)。下面是流程要点。

1
选供应商

DeepSeek / 智谱 / 通义千问 / Kimi 四个预设卡片,baseURL 与 model id 已内置;或「其他」自定义任意兼容端点。

2
填配置 + 测试

已知供应商只填 API Key——模型由 alpha 内置目录(provider→model-id 映射)自动列出,无需手输;只有自定义端点才手填 Base URL + model id。Key 支持明文;「测试连接」探活后再保存。

3
保存即用 · 一 id 一行

写用户 opencode.jsonc 的 provider[](经白名单 IPC,见 spec §11),provider.add 即时生效免重启;配置的每个 model id 各成一行,方便随时切换。
