设计原则

一致、现代、居中可缩放 —— 沿用 alpha-ui 设计系统

两块全量重构:定制中心(7 个 tab,真实目录数据)与设置(仅 通用 + 快捷键)。统一语言:冷瓷白 / 石墨中性脊 + 单一克制 indigo;内容 居中固定最大宽度(定制中心 880 / 设置 640)、卡片随窗宽 容器查询 2↔1 列重排;卡片化行、现代开关、键帽快捷键。下方每个页面均可点击切换。切右上「深色」看暗色。

与现状的差异:① 浏览页从「纯文本列表行」升级为卡片网格(图标砖 + 来源徽标 + 运行时/密钥元信息 + 添加);② 连接器按分类分组;③「已安装」独立成可启停管理列表 + 空状态;④「创建」补导入(文件夹 / git / npm);⑤ 设置砍到两项,其余并入「通用」的分组卡片。零改 upstream(纯新增 alpha 组件,守 ADR-016)。
