产品设计门 · 会话工作区(整页)

一页装下会话的全部:左栏 · 单一顶栏 · 时间线 · 输入框 · 右栏四面板

会话工作区是产品的主战场。本稿给出它的整页终态:整页由 alpha 自有组件渲染、全量 --a-* 令牌,不再依附任何上游布局。五大块 —— 左侧栏、归并后的单一顶栏、时间线、底部输入框、右侧四面板边栏 —— 全部元素级呈现;右栏四面板(审查 / 文件 / 终端 / 产物)逐个出完整帧。

增量声明 · 本页首个整页稿

与上一稿的关系

会话工作区此前没有整页稿 —— 只有四份分面现行稿各管一块。本稿是它们的整页合成 + 两处全新设计,不重画任何已批分面。

收编 · 四份现行稿(零视觉改动)
  • 左侧栏 = shell-sidebar 稿:选中胶囊、项目树、账户区、侧栏内搜索,并按既定盘点补「定制中心 / 自动化」两个入口行。
  • 时间线 = conversation-timeline 稿的行类型原样(气泡 / 工具卡 / 分组 / 脚注),含已批的产物链接行增量。
  • 输入框 = composer 稿的会话形态原样:+ / 权限 / 智能体 / 用量环 / 模型 / 推理强度 / 发送。
  • 产物面板 = artifact-workbench 稿与产物链接行增量稿的预览面形态原样,仅画其嵌入右栏的上下文。
全新设计 · 顶栏与右栏(alpha 语言)
  • 单一顶栏:双层头部(外框面包屑 + 内瓤会话头)归并为一条 46px 顶栏 —— 面包屑、会话状态、右栏 / 终端开关。形态为全新 alpha 设计,不复刻任何旧头部。
  • 右栏四面板:审查 / 文件 / 终端 / 产物 tab 化。审查、文件、终端为全新 alpha 设计;旧面板只充当「要承载哪些信息」的能力清单,布局与控件形态全部按 alpha 设计系统重构。
  • 审查面板的 tab 胶囊与文件行语义承接 timeline 稿 ⑤ 节(已批的 alpha 化审查面板设计),再补齐元素级细节(折叠条 / 分块导航 / 行内评论 / 空态 / 拆分视图)。
与实机现状的关系
  • 实机现状 = alpha 薄外框 + 上游内瓤;上游布局迁移后 alpha 注入落空,页面视觉整体回退。本稿即「彻底摆脱注入」的终态:整页 alpha 自渲染,崩溃时进入 Alpha Recovery(REQ-090 单向门合同,明文禁止回退上游;恢复边界既定,不在本稿画)。
  • 既定盘点里顶栏的双 header 叠加、右栏与左侧脱节两项缺陷,在本稿分别以「归并单一顶栏」「右栏四面板 alpha 化」回应。
  • 上游右栏(审查计数 / 统一拆分 / 每文件统计、文件树、终端)仅作为信息架构清单被继承 —— 能力不缺失,视觉不锚定。
帧外纪律:帧内均为最终建议文案与示意数据(项目名 / 会话名 / 文件名 / 行号皆为演示值),不出现开发行话;增量标注(收编 / 全新 / 引用)只在帧外。

架构说明

应用分三层:外壳负责窗口与项目管理,会话层承载对话与工具执行,渲染层只消费设计令牌。样式变量集中在一处,组件不各自取色。

焦点样式统一为可见的焦点环;所有交互控件在键盘序里可达。

右栏切「产物」的整页语境:时间线被点的产物链接行保持高亮(左侧不滚动),右栏聚焦该文件 —— 列表卡 + 预览面均为已批形态。既批联动契约(焦点移入 / Esc 返回)沿用。

全新设计 · 单一顶栏(归并双层头部)

顶栏:一条 46px,面包屑 + 状态 + 两个开关

此前页面同时存在外框面包屑条与内瓤会话头,信息重复、高度浪费。归并后只留一条:左 = 项目胶囊 › 会话名(悬停显编辑笔,点击改名);中 = 会话状态胶囊;右 = 终端开关 + 右栏开关。品牌只在左栏出现,顶栏纯功能;会话操作(重命名 / 归档 / 删除)归左栏会话行菜单,上下文用量归输入框 —— 两处既定裁决沿用,顶栏不再堆料。

全新设计 · 右栏骨架(tab 化四面板)

右栏总体:四个面板,一套胶囊 tab,可拖宽、可收起

右栏是会话的「工作台面」:审查(本回合改动)、文件(工作区浏览)、终端、产物(生成的文档)。tab 用胶囊形态(与左栏选中 / 顶栏开关同一强调语义);tab 上带计数徽章与运行指示;左缘 6px 为拖宽热区,悬停亮出强调细线;收起后整列让位给时间线。

tab 条 46px,与顶栏同高对齐;激活 = 强调淡底胶囊;计数 = 中性小徽章(激活时随染);终端 tab 有任务运行时带绿色呼吸点。最右「›」收起整栏。

宽度调节:右栏默认 400px,拖宽范围 320–560px;左缘热区悬停 / 拖动时显示 2px 强调线(下方示意)。宽度按面板记忆。
收起态:整栏隐藏,顶栏右栏开关退为未激活;时间线回中(整页帧见下「状态变体」)。再次打开回到最后激活的面板与宽度。
