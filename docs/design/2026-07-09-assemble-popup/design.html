02交互细节(实现规格)

1两个触发器,一个弹窗:输入 @(token 续输过滤,选「引用类」回填文本)或点 ＋(按钮打开;选「引用类」直接插入文本)。键盘/滚动/空态/页脚与 / 菜单同族(REQ-072 底座)。
2计划模式 = 会话级 toggle:开启 → 弹窗行变「关闭计划模式」+ composer 出「计划」chip + placeholder 提示;三路可关(⊗ / 再选一次 / Shift+Tab);发送带 plan 档参数,无 chip = 引擎默认 build(参数缺省)。
3只读权限档时计划模式行禁用并如实说明(「只读档固定使用只读 agent」),不静默失效。
4内置子 agent 保留但降噪(拍板⑦):general/explore 中文一句话简介 + 「内置」尾签;个人装的签「个人」淡紫;内部档(alpha-automation 系)绝不出现;build/plan 是模式、不在 Agent 节。
5第三方主档(如自装 primary agent)动态出现在「添加」节模式区,选中后 chip 显示其名,交互同计划;没有则不出现(本模拟未含)。
6扩展节收敛:原 + 弹窗「文档/PDF/表格/连接器」四行同一动作 → 收敛为单行「扩展市场…」。
