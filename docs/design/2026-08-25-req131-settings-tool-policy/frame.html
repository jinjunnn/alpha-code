帧外说明一:内部协议工具(结构化输出的强制通道)与历史回放占位符不在本节出现 —— 前者不可配置、强制可用,后者不是真实工具;二者由窄测试锁死,不作为「缺身份也能跑」的先例。

帧外说明二:「新发现」「服务已变更」「计费」与「无法核验的注册」四类标记全部来自宿主核验清单的事实字段;第三方服务的自我描述(标题、说明、annotation)只能展示,不参与任何标记与判定。完整字段映射见同目录 design.md。

帧外说明三:精确 canonical 身份与绑定指纹只出现在「开发者详情」折叠区;正文行只用展示名。展示名撞名不借用身份 —— 判定一律走结构化 selector。

可访问性与两种外观

键盘

焦点顺序:返回 → 类别导航 → 组开关 → 行内控件(展开 → 三态 → 恢复继承 → 开发者详情)。三态是 radiogroup,左右键切换、空格确认;展开按钮 aria-expanded;Esc 关闭设置整页(沿用现有行为)。

读屏

每行朗读:名称 → 生效状态 → 原因(即「生效:…」一行)。写入成功以 polite 状态播报;保存失败与损坏横幅是 role=alert 并接管焦点,可 Tab 到「重试 / 重置」。锁定行朗读「不可更改」及原因。

浅色 / 深色

全部取 --a-* token,两种外观都按正文 ≥ 4.5:1、次要 ≥ 3:1 核对;状态点不是唯一信号,始终伴随文字。

Reduced motion

展开 / 收起与骨架闪烁在 prefers-reduced-motion 下取消动画,只保留最终布局;加载态用文字「正在读取…」兜底。
