# 首页 · 对话 · 搜索 · 产物:逐页审查与改稿

## 给 owner 的总结

这四页大多数时候能用,真正挡住任务的有两处,都在对话页:一是打开一段对话时,内容没读到之前是一片空白,
读失败了也一直空白,没有字也没有按钮;二是回复失败时卡片直接贴模型服务的原话,本机记录里真实出现过
「预授权拒绝: member-only model 需 active 会员」,用户看不出是「这个模型要会员、可以换一个」。

- **首页**:每次启动其实都落在「新对话」页,而「全局配置未生效」的提醒只挂在很少到达的另一张首页上,
  配置写坏了启动后看不到。其余是几处工程话(「草稿目录未就绪」「模型状态链尚未就绪」)。
- **对话**:除上面两处,顶栏会把没生成标题的对话显示成英文时间戳(侧栏却写「新对话」),
  助手停下来等你批准时顶栏还写「正在生成…」;用户消息下面写「发往 Build」「发往 Alpha-readonly」这类内部代号;
  往上翻着看历史时发出新消息,视图不动,看不到刚发的那条。工具名字、来源标签、生图过程都已有别的票在改。
- **搜索**:第一次出稿。今天按原始标题搜:侧栏写「新对话」的,在这里是英文时间戳,搜「新对话」反而搜不到;
  同名对话(本机有 6 个都叫「Greeting」)分不清;输入后按回车没反应;列表还没读到时也说「没有匹配」。
- **产物**:结构问题(混进别的对话的图、技术信息挡在前面、下载失败难恢复)已由已批的「结果优先」稿解决,
  这里只剩七句警告和出错文字是工程话。

修法全在现有组件里改文字、状态和一两处交互,不加页面、不加功能、不加设置项。拆成四张票(见文末),
其中对话页那张要等联网失败分层与命名迁移两张在途票先合。

## 怎么看的

对着 worktree 的 `origin/alpha`(`0717f7d59`)逐页读代码,按「打开这一页 → 看到什么 → 想做 X 点哪里 → 失败时看到什么」走一遍。
只读取证:owner 机器上的启动时间线日志(`~/Library/Application Support/ai.opencode.desktop/logs/*/startup-timeline.log`)
与引擎库的**副本**(只取标题分布、错误名与状态码、发往的模式名的计数,不读对话正文)。没有启动任何应用。
截图证据:owner 提供的 `img11`(生图会话的工作过程展开)、`img12`(工作过程摘要行)、`img4`(侧栏更新提示)。

## 逐页审查表

等级:**挡任务** = 用户在这一步做不下去;**误导** = 界面说的与事实不符或让人得出错误结论;**打磨** = 工程话或小别扭,
且在同一组件内改文字或布局就能做完。归属:「本稿 Tn」= 文末票表第 n 张;「已归 #n」= 别的票已拥有;「不改」附理由。
