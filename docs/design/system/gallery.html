Cool Graphite / Porcelain — the alpha-ui design system

A living styleguide, rendered straight from the real tokens and component CSS. The neutral spine is a cool, slate-tinted porcelain (light) / graphite (dark); a single restrained indigo carries every accent. Quiet, premium, Linear / Vercel / Raycast register.

Every color, size, radius, shadow, and motion value on this page resolves from var(--a-*) — nothing is hardcoded. The component swatches use the components' own CSS verbatim. The tokens.css in code remains the single source of truth; this file is a generated mirror. If they disagree, the code wins.

iWCAG targets stated in the visual system: body text ≥ 4.5:1, secondary ≥ 3:1. --a-text-tertiary lands ~4.5:1 (light) / ~4.2:1 (dark) — reserved for meta / placeholder, an accepted exception.

Accent · indigo

tokens.css
!Fills use --a-accent-solid, not --a-accent. In dark, --a-accent is a lighter indigo tuned for text/links; a solid fill of it under white would read ~2.6:1. --a-accent-solid is kept deep (#4f46e5) so a white label clears WCAG 4.5:1 on the button. --a-send is a softer, send-only indigo — do not swap the brand accent for it.
