# 设置 · 定制中心 · 自动化:逐页审查

改稿对照(明暗两套,`?theme=dark` 直接看深色):[`frame.html`](frame.html)。

## 给 owner 的总结

- **自动化**:页面能用,但有四处会让人误会。云端任务点「立即运行」其实在你这台电脑上跑,按钮上什么都没说
  (历史上接入云端时漏掉的分支);选了「云端」以后,「权限」「单次最长」「完成后通知」还能改,但云端不看它们;
  只用自带 Key、没登录 Code Puppy 账户也能选「云端」,要到保存才报「尚未登录或登录已过期」;「用 AI 解析」成功后
  提示里露出 `{desc}`(#998,还没修)。文字上满是「cron」「token」「run 产物」「standard 档」。
- **设置**:快捷键**挡任务**:提示写「⌘,」,框却只认 `mod+comma` 这种写法,照着填会存成无效组合;「新建会话」
  默认写成 ⌘N,实际是 ⌘⇧S;每行露出 `settings.open` 这类内部名。「通用」里几项开关点了没有任何变化(已核实,见 S6)。
  工具一节每条云端和第三方工具都挂「计费:未知」—— 程序里根本没有这项数据。
- **定制中心**:按 owner 指定简化结构。九个页签收成三个(连接器、技能、助手);去掉来源 / 许可证筛选、页签里套的
  筛选、黄色说明框、页脚说明和卡片上的工程标签(Tier-1、不使用沙箱、已验证的远程目录、兼容、1.0.0);列表行只留
  图标 + 名称 + 一行描述 + 一个动作;「导入」并进「添加」下拉;「处理前置条件」改成「设置」,状态直接写缺什么。
  另有一处**说错了**:添加确认框说会写 `~/.opencode/opencode.jsonc`,应用早已不写那个文件。

各等级条数:**挡任务 1 · 误导 10 · 打磨 31**(另有 6 条已归别票、1 条 alpha 已修待发版、1 条读过不改,不重复计)。
打磨里 A10–A12 要动主进程的原因串、H13–H19 是 owner 指定的结构简化,都超出「同一组件内」,仍列入:前者是 T19
点名要删的实现术语,后者属于 T18「修复范围限 owner 指定的这些体验」。
