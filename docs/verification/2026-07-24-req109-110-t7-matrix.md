## 工具边界(实测确认,指导后续 cell 执行)

t7-delay-proxy.mjs 是 host 级 CONNECT 代理:**可对 HTTPS 注入延迟(C2 已证),
但无法注入 HTTP 状态码**——隧道层的 401/400/502 被客户端读成 TLS/连接失败(→
transient-failure),而非可解析的 HTTP 状态。故 invalid-grant(可解析 400/401 →
登出)与 5xx 的真机注入需 **TLS MITM(mitmproxy + 证书)** 或 alpha-web 侧测试
开关。另:代理须全程存活且理想情况只作用于 token/account 端点——host 级注入会
连带影响同域 catalog(C2 尾部污染教训:引擎继承 HTTPS_PROXY,采样期杀代理导致
catalog/git 出站断链,不作产品判据)。
