## 断点清单(联调实测发现,逐一修复/登记)

### BP-1 ✅已修 — 网关流式计量 `waitUntil` 缺位 → OpenAI-wire 计费全量静默丢失(B 侧)
- **现象**:登录租户 3 次真实调用,`[ledger]` 有记录但 `[settle]` 从不出现,ECS 账本零累加,`summary` 全 0。
- **根因**:`meteredOpenAiStream` 的 `onSettle` 在**流收尾**触发,`meter()` promise 未经 `waitUntil` 注册(Anthropic 分支虽调 `waitUntil`,但同样在收尾回调里注册,已太晚)。CF Worker invocation 随响应 body 结束即回收 → `meter` 内首个 `await`(preauth 释放 / settle fetch)被整体取消:**无异常、无死信 spool、无落账**。成功路径又零日志 → bug 完全隐身。
- **修复**(`alpha-platform/packages/gateway/src/worker.ts`,commit `6fe49f3`,已 prod 部署 `379a31fb`):`deferMeter()` 在返回流式 Response **前**预注册 deferred `waitUntil`,收尾回调 resolve;三处流式 settle(chat/completions OpenAI-wire + Anthropic 分支、/v1/messages 流式)统一换上;settle/preauth fetch 补 `AbortSignal.timeout(10s)`(fetch 挂死会拖死 waitUntil 且 catch/spool 不执行);成功路径补留痕。
- **验证**:修复后 tail 见 `[settle] ok`,ECS `dailyTokens` 累加,UI summary 出数。gateway 202/202 unit 绿。

### BP-2 ✅已修 — 冷启动登录态丢失(A 侧)
- **现象**:app 冷启动后恒显示「未登录」,`alpha-auth.json` 凭证在但不生效,无任何日志。
- **根因**:`index.ts` 在 `app.whenReady()` **之前**调 `initAuthEnv`/`initByokKeys`;macOS `safeStorage` 在 ready 前不可用 → `decryptString` 静默失败(旧 `load()` 的 `catch{}` 吞掉)→ 凭证不加载、mode 回退 byok。BYOK 钥匙库同因走了明文兜底。
- **修复**(`index.ts`:`initAuthEnv`/`initByokKeys`/`injectByokKeysIntoEnv` 移到 `whenReady()` 之后、sidecar fork 之前;`alpha-auth.ts`:`load()` 区分「文件不存在」(静默)与「有凭证但恢复失败」(loud warn);`alpha-byok-keys.ts`:钥匙串可用时自愈重加密历史明文库)。typecheck + 97 tests 绿。
- **验证**:当前二进制经 CDP `auth.start()` 走完 OAuth → `logged-in/platform`(旧包 respawn 路径)。**冷启动保持登录的真机复验需重打包**(源码级时序修复,当前跑的是 v0.1.0 旧二进制)→ 标 shipped、verified 待 ship:mac。

### BP-3 ⚠️已登记 REQ-014 — 悬空会话路由致「Not found」白屏(A 侧 UX)
- **现象**:`opencode.global` 的 `tabs.recent` / `tabs` 指向已删除会话 id 时,冷启动整个 app 卡在左上角「Not found」纯文字白屏,无侧栏、无恢复入口。
- **触发**:本轮删测试会话后复现;手工从 global store 摘除悬空 `tabs.recent` + 过滤 `tabs` 后恢复正常。
- **归属**:alpha 恢复上次路由的逻辑无「目标会话不存在」兜底 → 登记 **REQ-014**(P2 ux,alpha 杠杆=路由恢复前校验会话存在,失败回退首页而非死屏;关联 B11 呈现面)。
