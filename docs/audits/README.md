# Audit evidence

This entire tree is immutable point-in-time evidence. It includes summaries,
screenshots, captured payloads, portability checks, regression baselines, and
real-machine verification. The repository has not compressed or discarded the
protected audit corpus.

An audit proves only what was observed at its recorded time. Embedded REQ,
Sprint, status, plan, TODO, or checklist language is frozen evidence and does
not own current delivery state. Current behavior comes from code and tests;
active actions belong in [GitHub Issues](https://github.com/jinjunnn/alpha-code/issues).

Notable reusable baselines include frontend seam checks, Extension Hub visual
verification, Windows portability, legacy session-adapter behavior, and the
most recent real-machine captures. New audits use a dated path and link their
owning Issue or PR.
