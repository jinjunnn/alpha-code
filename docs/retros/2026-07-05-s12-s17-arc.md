**证实**:

4. **AlphaBoundary 下沉边界**(S17 T4)——throw 实测:比上游更内层先命中,局部降级成立(§7h 教训闭环)。

**证伪(重要教训)**:
1. **「本地门 ≡ CI」曾双层失守**:① husky prepare 每次 `bun install` 重置 hooksPath(「配置过又失效」真因,REQ-015);② `bun --cwd X run Y` 在 bun 1.3.x 打印 usage 后静默退出 0 —— **alpha-check 与 alpha-ci 的 typecheck 关双假绿**(REQ-027)。两者已根治(alpha 自有 `.githooks` 默认化 + 自愈重挂;flag 移 `run` 后)。**教训:门必须自证——「绿」需要能变红的证据(红绿探针);hook 输出出现不该有的 usage dump = 立刻怀疑 placebo。**
2. **「静默假成功」一日三抓**:上例之外,`-readonly` 会话 `.backup` exit 0 不写文件(T3)——催生「备份必验、验不过即删」纪律。反 placebo(C28 一族)已从 UI 层扩展到工具链层。
3. **REQ-014「alpha 恢复层」假设**——恢复由上游冻结 tabs.tsx 主理,alpha 无插入层;且实测毒态(旧格式 recent key)呈现为**整屏**上游 ErrorPage → 方案①(renderer 守卫)无效,方案②(main 预清)手工实证可达。
4. **v2「SDK 唯一真相源」**(ADR-014 v2)在 S12 已证伪(fs 类无 SDK 真相)→ v3 账本修正,本 arc 真机进一步坐实 v3 正确。
