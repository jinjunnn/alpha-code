## [Unreleased]

### Changed
- **平台模型清单收口**(REQ-030,云端已生效):国内版默认只显示国内系当代模型(DeepSeek V4 两档);DeepSeek 旧代(Chat/Reasoner)下架,存量会话/默认模型自动降级到 V4 对应档不报错。模型清单改为云端配置文件单一真源,后续增删模型不再需要发新版 app。
- **平台模型欠费自动切换**(REQ-031,云端已生效):运营方某家模型账户欠费时,同一模型自动切换到备用通道(OpenRouter)继续服务,计费按实际通道价目;全部通道不可用时如实报错,不静默。
- **「创建技能/Agent」从表单改为对话式**(REQ-036,需下个签名版本生效)——定制中心的裸表单(要求手写 markdown)已移除;现在直接在会话里说「帮我创建一个技能/agent」,出厂内置的 skill-creator 与 agent-creator 会访谈、生成并写盘,创建完成后当前会话下一条消息即可用(免重启)。「导入」(文件夹/git/npm)保留并成为该 tab 的主语义;技能市场中出厂内置的条目显示「出厂内置」而非「安装」。逃生开关:`ALPHA_FACTORY_SKILLS_DISABLE=1`。

### Fixed
- **冷启动不再因残留的旧标签页记录整屏卡死**(REQ-014,需下个签名版本生效)——历史版本残留的旧格式「最近标签页」记录、或指向已删除会话的标签页,此前会把整个界面卡死在报错页/「Not found」白屏且无任何恢复入口(只能手工删配置自救)。现在启动时自动清理这类坏记录(main.log 留痕说明剔除原因),正常标签页恢复不受影响;引擎一时连不上时按原样放行,绝不越修越坏。
- **「推理强度 / 权限档」切换偶发误报『切换失败』修复**(REQ-043,需下个签名版本生效)——切换的实现是驱动引擎控件逐档轮转、读回界面文本确认;此前固定等 90ms 读一次,引擎界面更新稍慢就会被误判为「转满一圈没命中」而报失败(实际已切成功)。现在等到文本真实变化再判定,更新慢不再误报、典型切换还更快;真失败(模型没有该档 / 控件无响应)仍如实提示,不装成功。
- **丢弃陈旧本地默认服务器现在留痕并自动清理**(REQ-042,需下个签名版本生效)——REQ-040 的「自动丢弃易失本地默认」此前无声进行,且陈旧记录永留、每次开机重判;现在 main.log 记一行说明原因,并把陈旧记录一次性清除。
- **冷启动偶发卡「无法连接到 Local Server」修复**(REQ-040,需下个签名版本生效)——若历史上把某个「具体端口的本地服务器」设成过默认,之后每次启动都可能连到一个已失效的端口而整屏卡住(内嵌引擎每次用随机端口)。现在这类易失的本地默认会被自动丢弃、回退到当次真实引擎,不再卡死。
- **推理强度对 DeepSeek 等模型接真**(REQ-041,需下个签名版本生效)——此前 DeepSeek(国内版默认模型)的「推理强度」显示的档位与引擎实际不一致,且点选会「切换失败」(根因:该模型档位是英文 low/medium/high,而控件只认中文低/中/高)。现在中英文档位统一,显示与实际一致、可正常切换;模型确实没有的档位会诚实提示,不再假装。
- **操作失败不再无声**(B11,需下个签名版本生效)——多处「点了没反应」的静默失败补上了提示:①侧栏会话右键菜单「分享」以前把生成的分享链接**直接丢弃**(点了像没反应),现在复制链接到剪贴板并弹提示;「删除 / 重命名」网络失败会弹「删除失败 / 重命名失败」,不再让条目诡异复原;②定制中心「内置能力治理」应用/加载失败此前静默(改动没生效却无提示,甚至有覆写现有治理配置之虞),现在会弹错误并保留原状;③自动化「保存 / 删除」失败此前静默,现在弹错误提示。(「复制对话」此前已有提示,不变。)
- **登录失败不再「点了没反应」**(B11,需下个签名版本生效)——浏览器授权后回到 app 若登录没成功(授权被拒 / 回调残缺 / 登录状态过期 / 网络兑换失败),此前只写日志、界面毫无表示;现在弹「登录失败」提示并按原因给出说明。已知边界:回调把 app 从未运行状态冷启动时提示不出现(界面停留在未登录态,再登一次即可)。
- **引擎连崩停止自愈后界面明确告知**(B11,需下个签名版本生效)——内嵌引擎连续崩溃、自动重启放弃后,此前只写日志,界面看着正常但所有会话都失灵;现在侧栏出现常驻红色横幅「引擎已停止运行」+ 错误提示,并带「重试」按钮(重试重新给满自愈机会)。
- **新会话创建失败不再静默落草稿**(B11,需下个签名版本生效)——项目上新建会话失败时此前静默跳到草稿页;现在弹「会话创建失败,已打开草稿」。侧栏会话操作的提示文案(重命名/删除/分享)同批接入中英双语。
- **首页输入 `/` 现在真的会弹出命令菜单了**(REQ-038,需下个签名版本生效)——此前首页占位文案写着「输入 / 调命令」但能力并不存在(用户报 bug)。现在首页与会话页共用同一命令数据源(内置 + 自定义 + 技能生成的命令),`/` 过滤、↑↓ 选择、回车执行/回填与会话页一致;`@` 引用也一并接线(agent + 项目内文件搜索),引用会作为真实上下文随消息发送。中文输入法组合中回车不再误发(补齐 Safari 路径守卫)。
- **会话输入框发送按钮箭头被裁切** —— 箭头字形被挤出圆形按钮底部、贴着输入框边缘被切掉(用户截图)。根因是换肤层与上游图标容器的布局冲突,已修复,箭头恢复居中。(REQ-038,需下个签名版本生效)
- **会话页与首页的 `/` 命令菜单现在是同一个弹框**(REQ-038b,需下个签名版本生效)——此前会话页弹的是引擎自带的全宽菜单,与首页样式/密度不一致(用户反馈)。现在两处使用同一个 alpha 菜单组件:同数据源、同样式、同键盘交互;选中语义不变(自定义命令回填、内置命令直接执行)。
- **会话工具栏时而多出「上下文」文字、侧面板上下文 tab 时而失灵** —— 上下文用量环的注入逻辑会把侧面板「上下文」tab 的按钮误当作用量环搬进工具栏(所以「有的有、有的没有」:取决于该会话是否开着上下文 tab)。已修复:只收养真正的纯图标用量环,并自动清理此前被误搬的按钮。(REQ-038,需下个签名版本生效)
- composer 控件诚实化(C28,需下个签名版本生效):移除「只读」权限档——实测它与「请求审批」行为完全相同,宣称的「禁止写/执行」并不成立(真只读将以引擎 plan 权限档形式回归,REQ-028);「推理强度 effort」菜单明示「预设 · 暂未接入模型推理」,不再暗示影响推理(真接入随 REQ-029)。
- **定制中心「已安装」卸载/更新按钮点了没反应** —— 对技能/Agent/插件/云能力条目点「移除」或「更新」时静默失败(无任何提示),只有 MCP 连接器能卸。修复后四类条目均可正常卸载净除、更新。(仅打包版受影响;真机验收 REQ-016 时发现并修复)

### Added
- **自动化云端档位**(REQ-025/REQ-022,云端已就绪,客户端需下个签名版本):定时任务新增「云端」执行位置——应用不在线也按时在云上运行(调研类任务),打开应用时结果自动拉回项目的 .alpha/runs 留档;创建时明示数据边界(只上传任务描述文本,不上传项目文件)与预算硬帽;云端连续失败会自动停用并在列表显示原因;删除任务即停止云端触发。
- **推理强度真接入**(REQ-029,需下个签名版本生效):输入框的「推理强度」不再是摆设——对支持的模型(Claude Opus/Sonnet、GPT-5.4 Mini)选择 低/中/高 会真实改变发给模型的推理参数;不支持的模型该按钮如实禁用显示「—」,不再假装可选。
- **自动化增强**(REQ-024,需下个签名版本生效):①「standard 可写档」——定时任务可以修改文件、执行常规命令(破坏类命令被权限拦截;启用时有明确风险确认);②「用 AI 解析」——一句话规则解析不出来时,可让模型帮你抽取周期与任务(解析用的临时会话即用即删);③连续失败 3 次自动停用并通知(修复后一键重新启用);④「立即运行」按钮——手动跑一次,不影响原定排程。
- **任意连接器与 Agent 导入**(REQ-033,需下个签名版本生效):定制中心「创建」新增两个入口——「添加自定义连接器」可接入精选目录之外的任何 MCP 服务(粘贴一条 npx 命令或填一个 https 地址即可,密钥加密存储);「导入 Agent」支持 .md 文件导入,Claude Code 格式的社区 agent 会显示逐字段转换预览(能转的转、不能转的如实说明),确认后立即可用。创建页同时注明了各类扩展的跨生态兼容边界。
- **真·只读模式**(REQ-028,需下个签名版本生效):输入框权限档新增「只读」——选中后 AI 从引擎层被禁止修改文件与执行命令(不是界面文案,是真拦截),适合放心地让 AI 分析代码/调研;可随时切回。切换失败会如实提示并回退,不会显示只读却仍可写。
- **扩展市场脱离发版**(REQ-032,云端+客户端配合,客户端部分需下个签名版本生效):定制中心的目录改为从官网(alphacodeone.com)拉取——官方上架新技能后,进入定制中心即可看到并安装,不再需要等 app 发新版。目录带数字签名(被篡改会整体拒用并回退),下载的技能文件逐个校验指纹(不匹配拒装);断网时回退到内置目录,市场永不空白。首个远程上架技能:「规范化提交信息」。
- **官网新手指南**(REQ-026,已上线):alphacodeone.com/getting-started——从下载安装、登录到第一次对话的完整图文步骤,以及 10 条常见问题解答(登录无反应/额度不足/模型列表/权限审批/数据安全等),不需要任何技术背景。
- **内置能力治理**(REQ-037,需下个签名版本生效):定制中心「已安装」新增「内置(上游)」分组——可对引擎原生 agent(build/plan/general/explore)隐藏或禁用、以自己的提示词重写,可禁用内置技能(禁用后斜杠菜单仍会列出——引擎行为——但执行被拦并给出诚实说明),可用自己的模板重写内置 /init /review 命令;支持黑名单/白名单两种模式与一键重置。承重项(如自动压缩)受保护不可禁用,并说明原因;全部改动免重启生效。

### Fixed

### Security
- 应用加固:关闭 Electron 的三个代码注入原语(RunAsNode/NODE_OPTIONS/调试注入)、开启 asar 完整性校验;移除签名沙箱的 dylib 注入豁免组合;「用指定应用打开」收紧为编辑器白名单(白名单外改用系统默认打开)(C27/C25,需下个签名版本生效)
- 界面进程数据外传通道收紧:此前任何跨域响应都被强制放行读取(`ACAO:*`),叠加无 CSP,一旦渲染进程被注入即可向任意外站发请求并读回响应;现改为仅本机引擎(回环)放行 + 打包版注入内容安全策略(网络连接仅限本机;`ALPHA_CSP_DISABLE=1` 可临时关闭排障)(C24,需下个签名版本生效)

- websearch 改为始终走 keyless 公共端点(限流版):`EXA_API_KEY` 不再透传给引擎——自有 Exa key 用户如需恢复,设 `ALPHA_ENV_ALLOWLIST_EXTRA=EXA_API_KEY`(A6 附带)
