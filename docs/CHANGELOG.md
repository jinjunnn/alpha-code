## [Unreleased]

### Fixed
- **定制中心「已安装」卸载/更新按钮点了没反应** —— 对技能/Agent/插件/云能力条目点「移除」或「更新」时静默失败(无任何提示),只有 MCP 连接器能卸。修复后四类条目均可正常卸载净除、更新。(仅打包版受影响;真机验收 REQ-016 时发现并修复)

### Added
- 会话数据库安全带上线(C17+B14,需下个签名版本生效):
  - **升级前自动备份**:app 升级后首次启动、引擎将要迁移会话数据库时,先自动做一份已验证的快照(滚动保留 5 份,存于应用数据目录 `alpha-db-backups/`),留出降级逃生路。
  - **版本过新诚实拦截**:用旧版 app 打开被更新版本迁移过的数据库时,启动前弹窗如实说明(不再静默继续跑在不理解的数据上),可选退出升级 / 备份后继续 / 直接继续。
  - **损坏可恢复**:数据库损坏时启动不再只是「服务启动失败」——弹窗指引从最近备份一键恢复,损坏文件改名保留不删除。
  - **「数据」菜单**:新增应用菜单项,可随时手动备份、导出整库到任意位置(导出件经完整性验证)、打开备份文件夹。
- 自动化定时任务上线(REQ-021 A1,需下个签名版本生效):侧栏新增「自动化」——一句话描述(如「每天早上 9 点,检查本项目未处理的 TODO 并生成清单」)自动解析出周期,逐字段确认后保存,到点自动在指定项目里执行并把报告写进 `<项目>/.alpha/runs/`,完成弹系统通知、失败在侧栏亮红色角标:
  - **只读安全档**:自动任务只能读文件/检索/联网查询,不能改文件、不能执行命令,`.env` 类文件一律不读;全程零弹窗(无人值守设计),可写档后续版本提供。
  - **诚实边界**:任务只在应用运行时执行(不是后台常驻服务),界面明示;配套「登录时启动 alpha-code」开关;睡眠/关机错过的触发按策略跳过并留记录,不静默丢失。
  - **护栏**:单任务超时中断(默认 15 分钟)、全局每日运行上限、同一时刻只跑一个任务(被跳过的有记录);任务历史可回跳查看完整会话原文与 run 产物。
- 定制中心 M3 · 云能力分区上线(REQ-020,需下个签名版本生效):
  - **「云能力」tab 从占位变真内容**:平台连接器卡(实时连接状态)+ 三条云 pipeline(云代码审查 / 深度调研 / 文档生成);未登录或 BYOK 模式下条目灰显并如实说明原因,一键登录/切换平台模式点亮。
  - **每条云能力有完整介绍页**:输入契约、预算默认与上限、执行层、**上行数据明细**(送出去什么一目了然);云连接器详情列出 4 个云派发工具与数据边界。
  - **「启用」不动引擎配置**:只把 pipeline 加入本机可用列表(安装账本),供会话与自动化选用,停用即从「已安装」移除。
  - **云代码审查可从详情页直接派发**:选项目 → 自动取 git diff(只传 diff,绝不上传全库)→ 云端执行进度实时显示 → 完成后结果自动回流项目 `.alpha/runs/`。
- 云派发数据安全三道闸(ADR-021,对会话内 agent 派发与界面派发同一入口生效):派发信封超过 1MB 直接拒发(不静默截断);diff/目标文本里检测到密钥样式内容(API key/私钥块/token)拒发并指出具体字段;未声明保护路径时自动注入 `.env* / *.pem / .alpha/ / .git/` 排除清单。
- 定制中心 M2 · 横向导航 + 详情页(REQ-019 T1/T2,需下个签名版本生效):
  - **九个横向类目 tab**(推荐/连接器/技能/Agent/插件/套件/已安装/创建/云能力);「已安装」tab 带琥珀角标提示可更新数,可更新条目在列表顶部单列分组。
  - **每个条目有了介绍页**:点卡片进入详情(简介/许可证/版本/数据边界/运行时依赖/所需密钥),`待核实` 条目如实标注;`Esc` 逐级返回(弹框 → 详情 → 列表 → 关闭)。
  - **按类型分档的安装路径**:技能点「添加」即装即生效(免弹框);连接器/套件走确认框(密钥密文采集/组合清单);插件先看介绍页再安装,并明确提示「运行于引擎进程内」的风险。
  - **全局搜索**:切换类目不清空,输入即出跨类目分组结果;来源 / 许可证一键筛选。
  - **详情页逐类型内容**:连接器列「提供的工具」清单与数据边界(远程列目的主机、本地如实说明联网取决于所连服务);技能全文预览 SKILL.md;Agent 显示权限档摘要与系统提示预览;插件列 hooks 与「插件 ≠ 套件」说明;套件组合清单可逐项查看、逐项安装重试。
  - **进详情页即检测运行时依赖**(uv / node / git 实时探测),缺失直接给安装指引,不用等点「添加」才发现。
  - **更新通道**:目录钉版更新后,「已安装」tab 角标提醒,可逐条或全部更新(连接器更新走确认框以便重填密钥,不静默丢失)。
  - **导入**:本地文件夹(校验 SKILL.md 后入库)、Git 仓库(https 浅克隆校验)、npm 插件包 —— 全部落 `.alpha` 并记账,来源不明内容一律不执行。
  - **离线安装(供给链)**:官方推荐插件随 app 预打包,安装写绝对路径、全程零网络(弱网/断网也能装);新增官方只读「代码审查」Agent 一键安装。
  - **安装反馈**:检查依赖 → 安装中分阶段提示;失败一律行内展示(卡片 / 详情页),不再只弹一闪而过的提示。
- 定制中心全面升级(全类型通用化,REQ-018,需下个签名版本生效):
  - **装完即用、免重启**:安装技能 / Agent / 插件后,引擎自动重载,**当前会话下一条消息**就能用上——不再需要重启应用(此前技能/Agent 写盘后其实不生效);npm 型插件首次启用会后台下载依赖。
  - **新增 Agent 分区**:浏览内置 Agent(build/plan 等)与你自建的 Agent,一处创建、一处管理。
  - **「已安装」覆盖全部类型**:连接器 / 技能 / Agent / 插件统一列出,可查看类型、版本、状态,一键卸载(此前只有连接器可管、其余装完失管)。
  - **连接器密钥安全化**:安装需要密钥的连接器(GitHub / 飞书 / 语雀等)时可直接填密钥,密钥存本机安全文件(0600)、配置里只留引用**绝不明文**;卸载即吊销(此前根本没有密钥输入框,需 key 的连接器装了也不能用)。
  - **安装落点改为 alpha 自有目录**:技能 / Agent / 连接器 / 插件统一装进 `.alpha`(经软链桥接被引擎发现),不再污染你自建的 opencode 配置;检测到旧版安装可一键迁移(迁移开关随后续真机验证开启)。
  - 内置官方「skill-creator」技能(Apache-2.0)随包分发。
- 云任务结果自动落到项目里:agent 在会话内跑完云任务(cloud_* 工具)后,任务状态与产物自动写入项目根 `.alpha/runs/<任务id>/`(status/contract/artifacts),完成时右下角提示;`.alpha/` 自带 gitignore 不污染仓库(B3/ADR-019,需下个签名版本生效)
- sidecar 引擎崩溃自动恢复:引擎进程意外退出后 10 秒内自动重拉(指数退避,连续崩溃 5 次后停手防风暴);恢复未确认健康前不再刷新界面(防白屏)(B5)
- alpha 自有后端扩展开始随包分发:内置 `alpha_ping`/`alpha_echo` 工具(agent 工具表可见),是后续 alpha 自有工具/能力线的装载通道(B6/G1,需下个签名版本生效;`ALPHA_EXT_DISABLE=1` 可关)
- 模型目录按版本显隐(国内版/国际版):平台代理与内置「自带 Key」目录由网关白名单驱动,登录或打开模型面板即同步、无需更新 app;离线时回退内置目录并显示「内置目录」徽标;用户自定义添加的节点不受版本限制(REQ-001)
- 登录态自动续期:登录一次长期有效——token 到期前自动轮换刷新,不再出现「用着用着平台模型突然 401/要求重登」;仅当会话在网页端被撤销时才要求重新登录(B2,需下个签名版本生效)

### Changed
- 首页整洁化:移除 composer 下方与左侧栏重复的项目/会话快捷条(该黄金位留作后续功能入口);工作区切换 chip 与左侧栏项目导航保留(REQ-011,需下个签名版本生效)

### Performance
- 启动更快:sidecar 健康探测改为立即首查(此前每次启动固定先 sleep 100ms 再探测),常规启动约省 100ms(D1,需下个签名版本生效)

### Fixed
- 失败不再静默:项目列表加载失败在首页/侧栏均有明确提示与重试;定制中心「已安装」读取失败有顶部错误条;账户信息读取失败不再误显「钱包按量扣费」(改为「读取失败 + 重试」);全局 `opencode.jsonc` 写坏(语法错误或不认识的配置项)时首页给出「配置未生效」警示并可一键打开文件——此前引擎会静默忽略整份配置;启动等待期增加状态文字(B11/B23/B20)
- 云任务进度流更抗断:断连/空转改指数退避重连(不再风暴)、断点续传保真(非数字事件 id 不再丢)、任务结束判定更健壮、僵死连接 90 秒自动回收(REQ-003/C23)
- 启动提速:不再每次启动都等待登录 shell 探测(.zshrc 里 nvm/conda 慢时最坏 ~10s 黑屏)——上次结果缓存即开即用,探测转后台刷新(B1,首次启动仍会探测一次)
- BYOK 改密钥/删密钥即时生效:不再需要重启 app——改完立刻用新 key 调用,删除立刻吊销(此前旧 key 会滞留到重启)(B21)
- 界面回归根治:此前每日上游同步会静默打断 alpha 的界面定制(用户消息/工具卡/发送按钮/新对话等多处样式回落),已将上游前端冻结在 6/30 验证过的状态、每日同步只进引擎——同类回归物理上不再发生(REQ-013/ADR-020;界面恢复随下个版本生效)
- 平台代理用量计量:流式对话(OpenAI-wire)的 token 用量此前**全量丢失**、账户用量恒为 0——已修复,登录后经平台模型的每次对话都会正确计入今日/本周用量与套餐窗口(REQ-002 BP-1,网关侧)
- 冷启动登录态:app 重启后不再错误显示「未登录」——已存储的登录凭证在启动时可靠恢复(REQ-002 BP-2,需下个签名版本生效)

### Security
- 应用加固:关闭 Electron 的三个代码注入原语(RunAsNode/NODE_OPTIONS/调试注入)、开启 asar 完整性校验;移除签名沙箱的 dylib 注入豁免组合;「用指定应用打开」收紧为编辑器白名单(白名单外改用系统默认打开)(C27/C25,需下个签名版本生效)
- 界面进程数据外传通道收紧:此前任何跨域响应都被强制放行读取(`ACAO:*`),叠加无 CSP,一旦渲染进程被注入即可向任意外站发请求并读回响应;现改为仅本机引擎(回环)放行 + 打包版注入内容安全策略(网络连接仅限本机;`ALPHA_CSP_DISABLE=1` 可临时关闭排障)(C24,需下个签名版本生效)
- 自动更新不再允许降级:防止更新源被替换/重放旧版本把 app 打回含已修漏洞的版本(需要旧版时手动下载对应 Release 的 dmg)(B9)
- **第三方 MCP/LSP 不再继承你的密钥**:此前任何安装的连接器子进程都能从环境变量读到平台登录凭证与全部 BYOK 模型密钥;现改为白名单环境 + 文件通道,密钥不再进入子进程环境(附带:登出即时吊销密钥文件;`echo $ALPHA_API_KEY` 在 agent 终端输出为空属预期)(A6,需下个签名版本生效)
- websearch 改为始终走 keyless 公共端点(限流版):`EXA_API_KEY` 不再透传给引擎——自有 Exa key 用户如需恢复,设 `ALPHA_ENV_ALLOWLIST_EXTRA=EXA_API_KEY`(A6 附带)
- 定制中心内置连接器目录钉精确版本:一键安装的 MCP 不再每次在线解析 `latest`,消除版本漂移与供应链不确定性(钉值 = 更新当日各包 latest,行为一致仅冻结确定性)。存量已装配置的一键迁移随定制中心升级落地(迁移时按钉版重装),迁移开关随后续真机验证开启(A2/REQ-018)
