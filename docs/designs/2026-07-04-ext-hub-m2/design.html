核心:每种类型,点击之后发生什么

统一约定:卡片主体点击 = 看介绍(详情页),「添加」按钮 = 走安装路径。安装路径按类型分三档:直装(零配置零风险,点了就装)、确认框(有写入/密钥/多项,弹框确认后装)、详情页先行(高风险,必须先看介绍页,从页内安装)。

类型点卡片主体点「添加」安装路径与理由
技能 Skill 详情页(SKILL.md 全文 + 触发说明) 直装 无弹框,立即安装 本机纯文本文件、零配置零密钥、免重启生效、可秒卸 —— 摩擦降到零,装完 toast「已添加 · 当场生效」。失败(如资产未打包)在卡片/详情页行内红字,不静默。
连接器 MCP
无密钥/目录		 详情页(工具列表 / 传输 / 数据边界 / 依赖) 轻确认框 一行写入说明 → 确认 要写引擎配置(~/.opencode/opencode.jsonc)+ 运行时预检 —— 一步确认让用户知道写了什么。markitdown / fetch / playwright 属此档。
连接器 MCP
需密钥/选目录		 详情页(同上 + 所需密钥说明) 完整确认框 密文采集密钥 / 选目录 → 确认 GitHub / 飞书 / 语雀(密钥)、文件系统 / Git(选目录)。密钥可留空稍后配;密钥存本机安全文件(0600),配置只留引用。
Agent 详情页(模式 / 提示词预览 / 权限档摘要) 无「添加」 内置只读;自建走「创建」表单 内置 agent(build/plan)随引擎提供、不可装卸;自建 agent 创建成功后直接跳其详情页。将来目录 agent 上架时,因带权限档,归入「详情页先行」档。
插件 Plugin 详情页(hooks / 工具清单 / 风险说明) 详情页先行 点「添加」= 打开详情页,页内「安装插件」→ 带风险行的确认框 插件代码运行于引擎进程内(风险最高)+ npm 下载 —— 强制先看介绍页(hooks 挂点、贡献工具、npm 包名),从页内安装。参照 ChatGPT 插件详情页模式。
套件 Bundle 详情页(组合清单逐项状态,子项可点) 组合确认框 清单 + 预检状态 → 逐项扇出 多项一次装,确认框列出全部子项(即现版弹框);部分失败 → 详情页逐项重试。
云能力(M3) 详情页(输入契约 / 预算 / 上行数据说明) 无「添加」 操作 =「派发」,登录门控 不是安装物,是能力入口;M2 仅 tab 占位。
三档安装路径(时序)
技能·直装点「添加」→写入 ~/.alpha + 账本→重载引擎(~2s,免重启)→✓ toast「已添加 · 当场生效」
MCP·确认框点「添加」→确认框:预检 which → 采集密钥/选目录→写配置 + 密钥入安全文件→live 连接→✓ 已启用
插件·详情页点「添加」/卡片→详情页:hooks·工具·风险→页内「安装插件」→确认框(风险行:运行于引擎进程)→写配置,引擎自动 npm 装载→✓ 已安装
套件·组合点「添加」→确认框:清单 + 预检→按序扇出(密钥项逐个采集)→✓ n 项成功/m 项失败 → 详情页逐项重试

失败一律行内呈现(卡片错误 chip / 详情页 Banner),toast 只报成功 —— 对齐反静默纪律(B11)。

与 6-26 原稿的关系:token / tab 栏 / 卡片 / 确认框 / 管理列表全部沿用;连接器 / 套件 / 创建 tab 的列表页零改动。M2 新增 = 详情页层 + 上表的分档安装逻辑 + 有更新(并入已安装)+ Agent tab(M1 已上线)+ 云能力占位。

Q1 · 技能直装(无确认框)是否 OK?理由:零配置零密钥、本机文件、可秒卸 —— 弹框纯属摩擦。若你希望所有类型统一都弹确认框,改回也容易。
Q2 · 插件「详情页先行」是否 OK?点「添加」不直接装,先进介绍页(hooks/风险),页内再装 —— 参照 ChatGPT 插件详情页。若嫌绕,可改成「添加」直接弹风险确认框、详情页仅供浏览。
Q3 · 详情页返回方式:左上「‹ 类目名」轻量返回 + 点 tab 跳走 + Esc。够不够?
Q4 · 「云能力」tab 现在就挂(占位文案)还是 M3 做好再加?
