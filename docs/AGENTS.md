# Development documentation

- Use the shared `$maintain-repository-docs` skill during implementation,
  fixes, refactors, reviews, and releases with documentation impact.
- Treat GitHub Issues and Alpha Delivery as the only source of live work.
- Do not create or update a local backlog, Issue mirror, requirement status,
  priority, assignee, Sprint membership, or task checklist.
- Keep ADRs, designs, contracts, audits, runbooks, changelogs, retrospectives,
  and verification evidence durable and link them from the owning Issue.
- `BACKLOG.md`, `requirements/`, `sprints/`, `plans/`, and legacy `issues/`
  trees were removed after migration. Do not recreate live delivery trackers.
- Design sources, audit/QA evidence, decisions, retrospectives, and rule assets
  are protected history. Index their authority; do not delete them as stale
  delivery prose.
- Follow `jinjunnn/alpha-work/governance/documentation-standard.md`.
