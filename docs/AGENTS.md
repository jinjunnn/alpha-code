# Documentation governance

- Treat GitHub Issues and Alpha Delivery as the only source of live work.
- Do not create or update a local backlog, Issue mirror, requirement status,
  priority, assignee, Sprint membership, or task checklist.
- Keep ADRs, designs, contracts, audits, runbooks, changelogs, retrospectives,
  and verification evidence durable and link them from the owning Issue.
- `BACKLOG.md`, `requirements/`, `sprints/`, and legacy `issues/` content are
  read-only migration history unless a file explicitly states otherwise.
- Follow `jinjunnn/alpha-work/governance/documentation-standard.md`.
